# CrystalMelody

## Introduction
CrystalMelody is a media player capable of previewing files in various formats. It is built using Qt C++.

## Utilities

- **Play music and video**: *CrystalMelody* supports a wide range of media types. It will create a playlist that allows you to select different playback modes when you choose a folder to play.

- **View and Pin Image**: You can open an image file in *CrystalMelody*. Use the mouse wheel to adjust the size of the ImageViewer. Right-click to make the ImageViewer frameless and keep it always on top.

- **Video as Wallpaper**: If you enable "DynamicDesktop" switch, your wallpaper will be set to the dynamic video being played, if any.

- **Pack Files and Load Them without Unpacking** : You can pack your currently opened folder into a packed format `.crystal`. And then you can play media or view images directly from `.crystal` file without any extraction.

- **Aquire Music Thumbnail**: *CrystalMelody* allows you save the current music thumbnail as an independent image file.
